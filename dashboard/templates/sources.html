Comandi pipeline

Esegui da terminale per popolare il dataset con dati reali:

# Online (API reali, con cache su disco)
python scripts/01_build_dataset.py --mode online --n 50

# Offline (simulato, riproducibile)
python scripts/01_build_dataset.py --mode simulated --n 48

# Da file SAbDab locale
python scripts/01_build_dataset.py --mode sabdab --sabdab-path /path/to/summary.tsv

Nota sui calcoli PBEE

La modalità simulated di 04_compute_pbee.py genera ΔG predetti coerenti con la letteratura MMPBSA (bias ~−0.4 kcal/mol, σ ~1.2). Per calcoli PBEE reali è necessario installare APBS e PDB2PQR, e poi eseguire: 

python scripts/04_compute_pbee.py --mode apbs

Tutte le chiamate di rete usano cache locale in data/cache/
